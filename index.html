自己紹介

Webエンジニアとして約3年8ヶ月、PHP・Laravel・JavaScript・MySQLを使った業務システムの開発・保守を担当しました。社内約5名・クライアント側約5名の体制で、仕様の確認から設計・実装・テスト・運用保守まで一通り対応し、既存システムの仕様調査や不具合の原因切り分け、影響範囲を確認したうえでの改修を積み重ねてきました。

現在は Claude Code・Codex・ローカルLLM（Ollama）・n8n を使い、AIエージェントや業務自動化の仕組みを自分で作って毎日運用しています。AIに任せる部分と人が確認する部分を分け、動くものを小さく作って改善していく進め方を大事にしています。既存サービスで対応できることと、追加の開発が必要なことを整理し、目的に合う方法を一緒に考えます。

個人開発（AI・自動化）

営業支援AIエージェント

課題

案件探し・条件確認・応募文作成を手作業で行うと時間がかかり、応募数が伸びない。

やったこと

  • 案件候補を自動収集し、ローカルLLMで一次判定
  • 候補の本文から稼働時間・出社要否・報酬・募集状況・応募済みかを確認し、条件に合わない候補を除外
  • 応募文の下書きをAIで作成。AIが使えない場合は別モデル→人の順に切り替え
  • 重複処理の防止・ログ保存・途中から再開できる構成

結果

候補の選別と下書き作成の手間を減らし、送信は人が確認してから行う形で日次運用中。

  • Python
  • Playwright
  • Ollama
  • Codex
  • Claude Code
  • PowerShell

個人用AI開発基盤

課題

AIとの作業内容が会話ごとに途切れ、記録や引き継ぎ、定期的な情報収集に手間がかかる。

やったこと

  • Claude Code＋MCP＋フック＋Obsidianで、作業記録と引き継ぎを自動化
  • 自作MCPサーバー（読み取り専用）をOpenAPI化し、Open WebUIのローカルAIから利用
  • Claude Codeのヘッドレス実行で、ニュース収集→Notion記録を定期実行
  • Node.js製の管理画面で、Docker上の各サービスの状態確認・一括起動／停止

結果

作業の記録・通知・情報収集が自動で回る環境を作り、毎日の開発で使っている。

  • Claude Code
  • MCP
  • n8n
  • Node.js
  • Docker
  • Notion API
  • Telegram Bot

自宅AIサーバー（使っていないPCの再活用）

課題

AI関連の常駐サービスでメインPCのメモリが不足し、作業に支障が出ていた。

やったこと

  • 使っていないPCにUbuntuを入れ、VPN（Tailscale）内だけで使えるサーバーとして構築
  • Docker上でナレッジ検索（RAG）・ローカルLLM・n8n・写真管理を稼働
  • Obsidianのメモを毎日同期し、意味で検索できるようにした

結果

重い処理をサーバー側へ移してメインPCの負荷を下げ、蓄積した知見をAIから検索できるようになった。

  • Ubuntu
  • Docker
  • Tailscale
  • Khoj
  • Ollama
  • Open WebUI

DBD Viewer（動画ビューアアプリ）

課題

動画コンテンツを快適に閲覧・整理できるツールが欲しかった。

やったこと

YouTube動画を最大5視点で同期再生するWebアプリを制作。React / Zustandによる状態管理、再生位置の同期、URL共有、モバイル対応を実装し、Playwrightによる動作テストを整備。

結果

PC・モバイルの両方で動作するビューアとして公開。
